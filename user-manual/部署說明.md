# 我的使用說明書・電子版（Google Apps Script）

學生在平板或手機填寫，資料即時寫入 Google 試算表。老師有獨立的檢視頁。

## 檔案

| 檔案 | 作用 |
|---|---|
| `Code.gs` | 後端：讀寫試算表、驗證、覆蓋時自動備份舊版 |
| `Index.html` | 學生填寫頁 |
| `Teacher.html` | 老師檢視頁（需要密碼） |

## 安裝步驟

1. 開一個新的 Google 試算表，命名為「我的使用說明書」。
2. 在試算表上方選 **擴充功能 → Apps Script**。這樣建立的專案會自動綁定這份試算表，`CONFIG.SHEET_ID` 就不用填。
3. 把 `Code.gs` 的內容貼進預設的 `程式碼.gs`。
4. 左側 **檔案 → ＋ → HTML**，建立 `Index`，貼上 `Index.html` 的內容。
   （檔名只填 `Index`，Apps Script 會自動加上 `.html`。）
5. 同樣方式再建立 `Teacher`，貼上 `Teacher.html` 的內容。
6. 在編輯器上方的函式選單選 `setup`，按 **執行**。第一次會要求授權，按照畫面允許即可。執行完試算表就會出現「使用說明書」工作表與標題列。

## 部署成網頁

1. 右上角 **部署 → 新增部署作業**，類型選 **網頁應用程式**。
2. 設定：
   - **執行身分**：我（也就是你的帳號）
   - **誰可以存取**：知道連結的任何人
3. 按部署，複製網址。

- **學生用**：直接用這個網址。
- **老師用**：網址後面加上 `?page=teacher`。

這樣設定的好處是**學生不需要 Google 帳號、不需要登入**，平板開啟就能寫。

> 修改程式碼之後，要再執行一次「部署 → 管理部署作業 → 編輯 → 版本選『新版本』」，學生端才會看到更新。

## 設定

在 `Code.gs` 最上方的 `CONFIG`：

| 設定 | 說明 |
|---|---|
| `SHEET_ID` | 綁定試算表時留空即可 |
| `SHEET_NAME` | 資料存放的工作表名稱，預設「使用說明書」 |
| `TEACHER_PASSWORD` | 老師檢視頁的密碼，預設 `1940`，請自行更改 |
| `MAX_LEN` | 單一欄位字數上限，預設 1000 |

## 資料怎麼存

一位學生一列，以**班級＋座號**辨識。同一位學生再次儲存會覆蓋原本那一列，舊版自動留存在「修改紀錄」工作表，所以不會遺失。

欄位：更新時間、班級、座號、姓名、產品型號、使用方法、使用方法開放、充電、耗電、電力開放、注意事項、注意事項開放、故障排除、故障排除開放、保固條款、保固開放、兩週後回顧、原始資料（隱藏欄，供程式讀回編輯用）。

「故障排除」在試算表中以 `狀況｜原因｜做法` 的格式，一列一筆。

## 學生端的功能

- **空話偵測**：輸入「我很好相處」「隨和」「開朗」等詞會即時提醒，並提示改寫公式。
- **開放程度**：每一欄可選公開／小組／只給老師。注意事項預設為「只給老師」，其餘預設「小組」。
- **草稿**：邊寫邊存在自己的裝置上，不小心關掉也不會不見（僅限同一台裝置）。
- **載入我之前寫的**：輸入班級、座號、姓名可取回先前的內容繼續修改，三者都要正確才能讀取。
- **預覽**：排成一張說明書，可直接列印或截圖。

## 老師端的功能

- 以密碼登入，可依班級篩選。
- 「只看學生願意公開的」：隱藏學生標為小組或只給老師的欄位，投影時使用。
- 列印：一頁兩欄，適合印出來貼在教室。
- 開啟試算表：直接跳到原始資料。

## 安全性

- 所有輸入都會限制長度，並在寫入前處理掉以 `=`、`+`、`-`、`@` 開頭的內容，避免被試算表當成公式執行。
- 同時儲存時以 `LockService` 鎖定，避免兩位學生同時寫入造成資料錯亂。
- 老師檢視頁與試算表網址都需要密碼。但這是課堂用的簡易保護，不是嚴格的權限控管——真正的資料仍在你的 Google 帳號底下，學生無法直接開啟試算表。
