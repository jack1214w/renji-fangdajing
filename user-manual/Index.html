我的使用說明書

USER MANUAL　版本 1.0　本手冊由本人撰寫

如果你也有一本使用說明書，上面會寫什麼？別人要怎麼做，才不會不小心弄壞你？

三件事：每一欄都可以自己決定要給誰看。沒有人可以拿別人的說明書開玩笑。老師也會寫一份。
先看看小禾的說明書（寫之前建議看一下）
產品型號慢熱型・需預熱三分鐘
使用方法問我問題之後，請等我幾秒。我沒有馬上回答，不是不想回答，是還在想。
讓我用寫的，我可以寫得比說得清楚。
電力來源充電：有人跟我說「不急」。一個人看書的午休。
耗電：被催。很多人同時看著我等我講話。
注意事項請不要幫我把話說完。就算你猜對了，那也不是我想說的那句。
故障排除突然不說話了｜通常不是生氣，是還沒想好｜等我三分鐘，或說「你慢慢想」
保固條款踩到我的雷，直接說「對不起，我剛剛太急了」。我不會記很久。但如果你裝作沒發生，我會記很久。

這些詞不要用，因為別人讀完還是不知道要怎麼對你：

我很好相處隨和開朗普通還可以看情況

01產品型號

一句話形容自己，可以有點好笑。例：慢熱型・需預熱三分鐘

02使用方法

怎麼跟我相處會順？公式：當我＿＿＿的時候，請你＿＿＿，不要＿＿＿。因為＿＿＿。

03電力來源

什麼會讓我充電？什麼會讓我耗電？各寫一到兩件具體的事。

04【警告】注意事項

什麼話、什麼做法會讓我不舒服？這一欄最難寫，也最重要。你可以只給老師看。

05故障排除

三格都要填：狀況、可能的原因（通常不是別人想的那樣）、建議的處理方式。

06保固條款

如果有人不小心弄壞了你，他要怎麼修？什麼樣的道歉你收得下來？

07兩週後回顧

兩週後再回來填：有人照著我的說明書對我嗎？發生了什麼事？（現在可以先空著）
