# 人際放大鏡

一個給國小高年級的社會情緒學習（SEL）文字遊戲，適合資優班或綜合活動課使用。

玩家會遇到六位個性不同的同學，每個情境從四個回應中選出一句話，然後看見對方「心裡怎麼想」。說中對方真正在意的事，他的心理能量會提升；踩到雷區，他會受傷，玩家的「友感帳戶」也會減少。

## 遊玩

開啟 [遊戲頁面](https://jack1214w.github.io/renji-fangdajing/)，或把 `index.html` 下載到電腦上，用瀏覽器直接開啟（沒有網路也能玩，只是手寫字體會換成電腦內建字型）。

## 設計理念

這個遊戲是「特質拍賣」活動的延伸。特質拍賣讓學生思考自己重視哪些特質；人際放大鏡則把視角轉向別人：每位同學身上，都有大家看得到的**表面特質**，也有藏在底下、他**真正在意的事**。

分數只是讓學生願意玩下去的引擎，真正的教學價值在每一句「心裡想」。學生選了一句自以為很好的話，卻看到角色心裡想「又是天分。大家都只看到畫完的樣子」，那一刻的落差，就是學習發生的地方。

三個貫穿全遊戲的訊息：

- **看見表面底下的事**：大家看到的特質，不一定是他最在意的。
- **好聽的話，不一定是對的話**：每一章都有一個「看起來很善良」的陷阱選項。
- **說錯話之後可以修補**：比永遠不說錯更重要的，是說錯之後怎麼辦。

## 兩種模式

開場畫面可以切換模式，切換需要教師密碼（未公開，請向使用單位索取）。

| | 課堂模式 | 學生模式 |
|---|---|---|
| 用途 | 老師投影，帶全班一起玩與討論 | 學生個人操作 |
| 章節 | 小宇、小晴、阿凱（可自由選章） | 小芸、阿翔、小禾（依序進行） |
| 中途放大鏡 | 關閉，特質留到結局揭曉 | 每章 2 次 |
| 結局題標題 | 和同學討論 | 想一想 |

設計上是先由老師帶全班走過三個示範故事並討論，再讓學生用三個全新的故事自己練習。學生版三章的「正確回應類型」刻意各不相同——接住焦慮、溫和地說界線、安靜地等待——避免學生歸納出「選最溫暖的那句就對了」的套路。

## 六個角色

| 角色 | 表面特質 | 真正在意的 |
|---|---|---|
| 小宇 | 創造力 | 毅力，希望有人看見他練了很久 |
| 小晴 | 同理心 | 被理解，她的感受被當真 |
| 阿凱 | 學習力 | 歸屬感，希望大家願意跟他一起 |
| 小芸 | 認真負責 | 不完美也被接納 |
| 阿翔 | 知識豐富 | 分享帶來的連結 |
| 小禾 | 安靜、有想法 | 被給時間 |

## 遊戲規則

每個情境有四個回應，順序隨機：

| 類型 | 心理能量 | 意思 |
|---|---|---|
| 精準命中 | +20 | 說中角色真正在意的事 |
| 命中表面 | +5 | 角色會開心，但還沒有被真正看見 |
| 無關 | 0 | 和角色的特質無關 |
| 踩雷 | −15 | 讓角色受傷，並進入修補回合 |

踩雷後一定會進入**修補回合**：好好道歉並回到對方在意的事，可以拿回六成損失並得到修復徽章；替自己辯解會讓損失加倍；用東西討好或延後處理，則什麼也沒有改變。
