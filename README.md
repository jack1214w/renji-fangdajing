# 人際放大鏡

國小高年級的社會情緒學習（SEL）課程教材，適合資優班或綜合活動課使用。

課程從「特質拍賣」延伸而來：特質拍賣讓學生思考自己重視哪些特質；這一系列則把視角轉向別人——每位同學身上，都有大家看得到的**表面特質**，也有藏在底下、他**真正在意的事**。

## 1. 人際放大鏡

玩家遇到六位個性不同的同學，每個情境從四個回應中選一句話，然後看見對方「心裡怎麼想」。說中對方真正在意的事，他的心理能量會提升；踩到雷區，玩家的「友感帳戶」會減少。

| | 課堂模式 | 學生模式 |
|---|---|---|
| 用途 | 老師投影，帶全班玩與討論 | 學生個人操作 |
| 章節 | 小宇、小晴、阿凱（可選章） | 小芸、阿翔、小禾（依序） |
| 中途放大鏡 | 關閉，特質留到結局揭曉 | 每章 2 次 |

切換模式需要教師密碼。設計上是先由老師帶全班走過三個示範故事並討論，再讓學生用三個全新的故事自己練習。

## 2. 午休失蹤檔案

午休鐘響，小禾的位子是空的，抽屜裡留著一本沒帶走的筆記本。

學生在校園六個場景中探索，蒐集九條線索，透過三層推理板拼出三件事：大家眼中的她、她真正在意的、最後一根稻草。找到她之後，還要決定對她說什麼。

像素風俯視視角，虛擬搖桿操作，適合平板。一節課（40 分鐘）可完成，25 格行動點。

這個故事裡沒有壞人——每個人都只是說了一句自己早就忘記的話。

## 3. 我的使用說明書

單元收尾活動。學生寫下自己的使用說明書：產品型號、使用方法、電力來源、注意事項、故障排除、保固條款。每一欄可自行決定公開、只給小組，或只給老師。

`user-manual/` 內含 Apps Script 的前後端程式碼，學生填寫的內容會即時寫入 Google 試算表。部署方式見該資料夾的 `部署說明.md`。
